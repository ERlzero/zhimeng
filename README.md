# 织梦 · Dreamweaver

输入一段文字，生成一片只属于它的梦境。**同样的文字，永远生成同样的梦。**

## 玩法

- 输入文字，关键词会「长」出对应的意象：**星、月、云、草浪、山、海、雨、雪、花、鸟、流萤**
- 文字的情绪（暖 / 冷）决定梦境的色调
- 🖱️ 移动鼠标惊起流萤，👆 点击画面绽放一朵花
- 生成的梦境会把文字编码进 URL，复制链接即可分享同一个梦

## 技术

- 纯 HTML / CSS / JS，零依赖、零构建
- Canvas 2D 渲染，种子哈希 + 值噪声驱动，保证确定性
- 情绪词映射三套配色主题（暖 / 冷 / 梦幻）
- 核心逻辑分层：纯函数（Node 可测） + Canvas/DOM 接线

## 本地预览

直接打开 `index.html`，或用任意静态服务器：

```bash
python -m http.server 8000
```
